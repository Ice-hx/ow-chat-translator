# OW 聊天翻译器 v3 · 使用说明

韩语 / 英语 / 日语 ↔ 中文 · 完全离线 · 不注册、不联网

---

## 一、启动

1. 双击 `OWTranslator.exe`
2. 首次启动等 **5–15 秒**：先加载 OCR，再把 7B 模型读进显存
3. 状态栏显示「就绪（CUDA · 7B）」即可用

> 窗口置顶，可拖到屏幕角落。

---

## 二、选语言（v3 新增）

窗口上方两个下拉框：

| 选项 | 作用 |
| --- | --- |
| **源语言** | 自动 / 中文 / 韩语 / 英语 / 日语 |
| **目标语言** | 中文 / 韩语 / 英语 / 日语 |

**「自动」怎么工作：**
- 识别出来是外文 → 翻成中文
- 识别出来是中文 → 翻成你选的目标语言（默认韩语）

**手动指定**（比如只玩日服）：源语言选「日语」，省掉自动判断，更快更准。

---

## 三、两种用法

### 用法 A：热键一键翻译

1. 第一次点 **「框选聊天区域」**，框住游戏聊天框（自动保存）
2. 之后按 **F8**：自动截图 → 识别 → 翻译 → 显示

### 用法 B：手动

- **粘贴截图**：`Win+Shift+S` 截图 → 回到窗口 `Ctrl+V`
- **手打文字**：输入框输入 → `Ctrl+Enter`

### 回话

把目标语言选成韩/英/日 → 输入中文 → 复制译文 → 游戏里粘贴。

---

## 四、游戏设置

**必须用「无边框窗口」模式**（设置 → 视频 → 显示模式）。
独占全屏下，置顶窗口会被游戏盖住。

---

## 五、安全说明

- 不注入游戏进程、不读内存、不改游戏文件
- 只读取你截图后的图片，和微信截图没有区别
- 不触发反作弊

---

## 六、性能

| 项目 | 说明 |
| --- | --- |
| N 卡（CUDA） | 翻译 0.2–0.5 秒/句 |
| 无 N 卡（CPU） | 2–5 秒/句 |
| 显存 | ≥ 6 GB（7B 模型约 5.5 GB） |
| 磁盘 | 约 6 GB |
| OCR | 1–3 秒（含小字号自动放大；日语/英语首次会下载 10–16 MB 模型） |

## 七、常见问题

**Q：日文/英文识别不出来**
A：源语言选「自动」时，程序会先试韩语模型、再试中日英混合模型，会多花 1–2 秒。
如果只玩一个服，把源语言直接指定成对应语言，更快。

**Q：自动模式把日文认成韩文**
A：v3 已用「韩文字符占比」判断修正；若仍出现，手动把源语言设为「日语」。

**Q：中→英/日翻得不像游戏口语**
A：常用喊话已内置术语表和示例；冷门句子仍可能偏书面。可以反馈具体句子。

**Q：热键 F8 没反应**
A：被别的软件占用。改 `config.json` 的 `hotkey`（F1–F10）。

**Q：显存不够**
A：关掉其他程序；或换 3B 模型（`config.json` 里 `"model": "3b"`，需自备模型文件）。

## 八、配置文件

```json
{
  "src": "auto",
  "tgt": "zh",
  "zh_target": "ko",
  "region": [0, 0, 800, 200],
  "hotkey": "F8",
  "model": "auto"
}
```

- `src`：`auto` / `zh` / `ko` / `en` / `ja`
- `tgt`：`zh` / `ko` / `en` / `ja`
- `zh_target`：输入中文时默认译成的语言

## 九、目录结构

```
OWTranslator\
├─ OWTranslator.exe
├─ README.md
├─ config.json          运行后生成
├─ _internal\           运行库
├─ runtime\
│  ├─ llama\            CPU 推理引擎
│  └─ llama-cuda\       CUDA 推理引擎（优先）
└─ models\
   ├─ qwen2.5-7b-...-00001-of-00002.gguf
   └─ qwen2.5-7b-...-00002-of-00002.gguf
```

**模型是分片的，两个文件必须都在。**
