========================================
 守望聊天翻译器 · 使用说明（分卷版）
========================================

一个离线运行的韩中双向翻译工具，给在韩服打守望先锋的朋友用。
看懂队友说什么，也能把你想说的话翻成韩语发出去。

不需要联网、不需要注册、不需要 API Key。


----------------------------------------
一、先合并分卷
----------------------------------------

你拿到的应该是这几个文件（缺一个都不行）：

    OWTranslator-portable.zip.001   1.77 GB
    OWTranslator-portable.zip.002   1.77 GB
    OWTranslator-portable.zip.003   1.52 GB
    合并解压.bat
    使用说明.txt（本文件）

【最简单的办法】
把上面 4 个文件放在同一个文件夹里，双击「合并解压.bat」，
等几分钟，它会自动合并、解压、删除临时 zip、启动程序。

【手动办法】
1) 打开命令提示符，进入这个文件夹
2) 输入下面这一行（注意是同一行）：

   copy /b OWTranslator-portable.zip.001+OWTranslator-portable.zip.002+OWTranslator-portable.zip.003 OWTranslator-portable.zip

3) 得到 5.06 GB 的 OWTranslator-portable.zip
4) 用 Windows 自带解压或 7-Zip 解压

【校验（可选）】
分卷的 SHA256 记在 checksums.txt 里。
合并后整个 zip 的 SHA256 应该是：
b1238ae413d4d55d9b8d2b5a12fb8f24a5b0728051ad4bb93780c468ba35fbe8
对得上就说明文件没传坏。


----------------------------------------
二、启动程序
----------------------------------------

解压后是一个 OWTranslator 文件夹：

    OWTranslator\
      OWTranslator.exe       ← 双击这个
      README.md
      _internal\
      runtime\
      models\

注意：不要只把 exe 拿出来，模型和运行时都在旁边。

双击后等 5~15 秒：
  · 先加载文字识别
  · 再把 7B 模型读进显卡

顶部状态栏显示「就绪（CUDA · 7B）」就可以用了。


----------------------------------------
三、两种用法
----------------------------------------

【用法 A：热键一键翻译（推荐）】

  第 1 步：点程序里的「框选聊天区域」
           屏幕会变暗，用鼠标把游戏聊天框拉一个框
           （框一次就记住了，下次不用再框）

  第 2 步：在游戏里队友一说话，按 F8
           程序自动截图 → 识别韩语 → 显示中文

  说明：按 F8 时程序窗口会先自动隐藏，截完再出来，
        不会挡住游戏画面。

【用法 B：手动】

  · 粘贴截图：Win+Shift+S 框选聊天 → 回到程序按 Ctrl+V
  · 手打/粘贴文字：输入框里输入 → Ctrl+Enter

【回话（中→韩）】

  1. 上方切换成「中→韩」
  2. 输入你要说的中文，比如：给点治疗，我没血了
  3. 得到「힐 좀 줘, 피 없어」
  4. 点「复制译文」，切回游戏粘贴发送

「自动」模式下不用手切：
  检测到韩文就翻成中文，否则翻成韩文。


----------------------------------------
四、游戏必须这样设置
----------------------------------------

设置 → 视频 → 显示模式 → 选择「无边框窗口」

不能用「独占全屏」。
独占全屏下，任何置顶窗口都会被游戏盖住，你就看不到译文了。


----------------------------------------
五、安全说明（重要）
----------------------------------------

本程序：
  · 不注入游戏进程
  · 不读取游戏内存
  · 不修改任何游戏文件

它只做一件事：把你截图后的一张图片读出来，识别文字再翻译。
和微信截图、OCR 软件没有区别，不会触发反作弊。

但仍请注意：在任何游戏中使用第三方工具，
风险由使用者自己承担，请自行判断。


----------------------------------------
六、电脑要求
----------------------------------------

  系统    Windows 10 / 11 64 位
  显卡    NVIDIA 显卡（有 CUDA 会非常快，0.15~0.5 秒/句）
          没有 N 卡会自动退回 CPU，约 2~5 秒/句，仍然可用
  显存    建议 6 GB 以上（7B 模型约占 5.5 GB）
  内存    建议 16 GB
  硬盘    约 6 GB
  CPU     需支持 AVX2（2013 年后的 Intel / AMD 基本都支持）


----------------------------------------
七、常见问题
----------------------------------------

Q：状态栏一直停在「正在启动本地模型」
A：多半是显存不够。关掉浏览器、游戏外的其他程序再试。
   仍不行的话，需要换小一号的 3B 模型（找维护者要）。

Q：按 F8 没反应
A：可能被其他软件占用了这个热键（比如录屏、语音软件）。
   关掉冲突软件，或改 config.json 里的 "hotkey"（F1~F10）。

Q：提示「剪贴板里没有图片」
A：要先用 Win+Shift+S 截图，直接复制文字不算图片。

Q：识别出来的字是乱的
A：框选区域太小或太糊。框的时候上下留一点余地，
   不要贴着字切；也可以把游戏分辨率调高一点。

Q：翻译有点怪
A：短句和俚语偶尔会偏。常用喊话（治疗/大招/后撤/集合/别送了）
   已经写死词典，优先走词典，基本不会错。

Q：双击没反应 / 被杀毒软件拦了
A：PyInstaller 打包的程序常被误报，加白名单即可。
   它不联网，可以用防火墙确认。

Q：想改区域 / 换热键
A：同目录下的 config.json，删掉就恢复默认（区域要重新框）。
